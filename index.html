A live platform where learners practise spoken English on audio and video calls with real people. I designed, built and deployed every part of it on my own.

Pay-per-minute speaking practice

Solo developer · design, backend, frontend, payments, deployment, Android

Callers buy minute packages and connect to available speakers. Speakers earn per minute. Calls run peer-to-peer over WebRTC, while a Flask and Socket.IO server handles matching, signalling, billing and an admin panel where plans and prices can be edited without code.

The same site is packaged as an Android app (Trusted Web Activity) and is in Google Play testing, with Google Play Billing built in behind an admin on/off switch.

Data lost on every deploy

SQLite lived inside the container. I migrated production to Neon PostgreSQL, so data now survives redeploys.

Database locks under load

Concurrent writes blocked each other in SQLite. Enabling WAL mode fixed it during development.
